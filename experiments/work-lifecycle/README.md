# Optional lifecycle prototype

The October 22 prototype source is retained for inspection and the supported GoalFlow subset. Run `python -m scripts.validate_lifecycle` from the project root. It executes 38 deterministic cells across coding and research in fresh temporary directories.

The optional Restate/Paperclip backends are not required by the core demo or CI. Backend setup requirements and attribution are documented in their subdirectories. No full comparison was rerun during release packaging. The unchanged historical aggregates are in the root `evidence/lifecycle/` directory; raw runtime logs, stores and full original experiment layout remain private. Historical analysis/walkthrough regeneration requires that complete private layout and is not a public verification command. See `SPEC.md` and `DECISIONS.md` for contract and historical corrections.
