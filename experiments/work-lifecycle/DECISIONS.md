# Decisions and deviations

- 2026-10-22: Authorized implementation of the bounded comparative prototype. Existing archives remain unchanged; all new work is under this experiment directory.
- 2026-10-22, before lifecycle implementation: Use native Restate server because Docker is installed but its daemon is unavailable. SDK/runtime installation stays local to this experiment.
- 2026-10-22, before lifecycle implementation: Paperclip native deployment requires Node >=24.11 and substantial workspace/Postgres services. Use exact pinned pure status-arbiter code plus custom SQLite adapter. This is an extraction study, not a full Paperclip product benchmark; all custom adapter code counts.
- 2026-10-22: `SPEC.md` version 1 freezes the decision rule, policy boundary, protocol and twelve required scenarios before backend lifecycle implementation. Supplementary tests may probe uncovered invariants but cannot replace failing required cases.
- 2026-10-22: Baseline coding run passed 24/24 cells before GoalFlow implementation. First GoalFlow coding run failed 12/12 at initialization: SQLite cannot switch journal mode inside an explicit transaction. Moved WAL initialization outside the mutation transaction; preserved the failed run. This is an implementation fix, not a contract change.
- 2026-10-22: GoalFlow then passed 12/12 coding cases. Full comparison passed 72/72 required cells and recorded identical backend hashes between coding and research. Worker artifacts are produced in separate local subprocesses; verifier and reviewer policy remain shared application code.
- 2026-10-22: Added supplemental concurrency, invalid-input and precommit-write probes because frozen serial schedules did not cover these boundaries. Review run passed 110/112 cells (72 required plus 40 supplemental), with two failures of the same Paperclip adapter bug in the two domains: JavaScript truthiness treats an empty object as true, while the Python boundary rejects empty evidence. Corrected custom assessment translation to reject empty collections. Upstream arbiter and vendored dependency are unchanged; this is not a Paperclip product defect. Failed traces are retained. Rerun all cases after this change.
- 2026-10-22: Final comparison passed 112/112 cells (72 required, 40 supplemental) and 10,742 assertion checks. All three backends retained identical source hashes between the two domains in that run. No post-research GoalFlow core changes were needed. Complete custom-source counts: Restate 343, Paperclip extraction 250, GoalFlow 228; excluding local runtime setup/management, Restate 220. GoalFlow's 8.8% reduction against the smallest comparator misses the frozen 30% gate. Decision: preserve the prototype; no framework expansion justified.
